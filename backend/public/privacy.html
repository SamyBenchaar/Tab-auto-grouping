Politique de confidentialité

Tab Context Grouper (extension Chrome) · dernière mise à jour : 15 novembre 2026

Tab Context Grouper regroupe vos onglets par sujet (« voitures », « restaurants », « voyage »…). Pour cela, l'extension envoie une description minimale de vos onglets à un service d'intelligence artificielle. Cette page explique exactement quoi, où, et pour combien de temps.

Données envoyées lors d'un regroupement

Pour chaque onglet concerné, et seulement au moment où un regroupement est lancé :

  • le titre de l'onglet, limité à 150 caractères ;
  • le nom de domaine (par exemple caradisiac.com) ;
  • le chemin de l'adresse, sans paramètres ni fragment, avec les identifiants longs masqués (e-mails, UUID, identifiants de documents…) ;
  • la requête de recherche, si l'onglet est une page de résultats d'un moteur de recherche ;
  • les noms des groupes déjà présents dans la fenêtre.

Jamais envoyés : le contenu des pages, les cookies, les formulaires, votre historique de navigation, les onglets épinglés, la navigation privée, les pages chrome:// et about:, ni les domaines que vous avez exclus dans les options.

Traitement et conservation

  • Ces données sont envoyées à l'API de l'extension, hébergée sur Google Cloud Run (région europe-west1, Belgique), puis au modèle Gemini sur Vertex AI, dans la multi-région Union européenne.
  • Elles servent uniquement à calculer les groupes, puis sont oubliées : elles ne sont pas stockées sur le serveur, et les journaux techniques ne contiennent que des compteurs, des durées et des messages d'erreur, jamais de titres ni d'adresses.
  • Google Cloud agit comme sous-traitant. Selon ses conditions, il n'utilise pas ces données pour entraîner ses modèles ; il peut les conserver brièvement (mise en cache, détection des abus).

Compte Google

La connexion avec Google sert uniquement à appliquer une limite quotidienne de regroupements par personne. L'extension demande la seule autorisation openid via l'API d'identité de Chrome :

  • l'extension ne reçoit ni votre nom, ni votre adresse e-mail, ni votre photo ;
  • le serveur reçoit un jeton d'accès temporaire, le vérifie auprès de Google, puis en déduit un identifiant pseudonyme (une empreinte de l'identifiant de votre compte Google) ;
  • seuls cet identifiant pseudonyme, la date du jour et un compteur sont enregistrés dans Google Cloud Firestore (europe-west1), puis effacés automatiquement au bout de 2 à 3 jours.

Données conservées dans votre navigateur

Vos réglages, un cache des classements (24 heures) et l'historique permettant d'annuler un regroupement restent dans le stockage local de Chrome, sur votre appareil. Ils ne sont jamais envoyés et disparaissent quand vous désinstallez l'extension.

Modes facultatifs

  • Gemini API direct : si vous saisissez votre propre clé d'API, les mêmes données minimales sont envoyées directement à l'API Gemini de Google, selon les conditions applicables à votre clé (l'offre gratuite peut autoriser Google à utiliser ces données pour améliorer ses produits).
  • Heuristique locale : aucun envoi, le regroupement se fait par mots-clés dans votre navigateur.

Ce que nous ne faisons pas

Aucune publicité, aucune revente, aucun profilage, aucun outil d'analyse d'audience ni de suivi. Les données ne sont transmises à personne d'autre que Google Cloud, pour le traitement décrit ci-dessus. L'utilisation des informations reçues des API Google respecte le règlement sur les données des utilisateurs du Chrome Web Store, y compris ses exigences d'utilisation limitée (« Limited Use »).

Vos choix

  • Excluez des domaines, passez en mode manuel ou en heuristique locale dans les options.
  • « Se déconnecter » dans les options révoque l'accès de l'extension à votre compte Google ; vous pouvez aussi le faire depuis myaccount.google.com/connections.
  • Les compteurs quotidiens s'effacent d'eux-mêmes ; pour toute question ou demande, contactez {{CONTACT_FR}}.

Privacy policy

Tab Context Grouper (Chrome extension) · last updated: November 15, 2026

Tab Context Grouper groups your tabs by topic ("cars", "restaurants", "trip"…). To do so, the extension sends a minimal description of your tabs to an AI service. This page explains exactly what is sent, where, and for how long.

Data sent when tabs are grouped

For each tab involved, and only when a grouping runs:

  • the tab title, cut to 150 characters;
  • the domain name (for example caradisiac.com);
  • the address path, without query string or fragment, with long identifiers masked (e-mails, UUIDs, document IDs…);
  • the search query, if the tab is a search engine results page;
  • the names of the groups already in the window.

Never sent: page content, cookies, form data, your browsing history, pinned tabs, incognito windows, chrome:// and about: pages, or the domains you excluded in the options.

Processing and retention

  • This data goes to the extension's API on Google Cloud Run (region europe-west1, Belgium), then to the Gemini model on Vertex AI, in the European Union multi-region.
  • It is used only to compute the groups and is then discarded: it is not stored on the server, and technical logs contain only counts, durations and error messages, never titles or addresses.
  • Google Cloud acts as a data processor. Under its terms, it does not use this data to train its models; it may keep it briefly (caching, abuse detection).

Google account

Signing in with Google is used only to enforce a daily limit per person. The extension requests the openid permission only, through Chrome's identity API:

  • the extension never receives your name, e-mail address or photo;
  • the server receives a short-lived access token, checks it with Google, and derives a pseudonymous identifier from it (a hash of your Google account ID);
  • only this pseudonymous identifier, the date and a counter are saved in Google Cloud Firestore (europe-west1), and they are deleted automatically after 2 to 3 days.

Data kept in your browser

Your settings, a 24-hour cache of classifications and the history used to undo a grouping stay in Chrome's local storage on your device. They are never sent anywhere and are removed when you uninstall the extension.

Optional modes

  • Direct Gemini API: if you enter your own API key, the same minimal data is sent directly to Google's Gemini API, under the terms that apply to your key (the free tier may allow Google to use it to improve its products).
  • Local heuristic: nothing is sent; tabs are grouped by keywords inside your browser.

What we don't do

No advertising, no selling of data, no profiling, no analytics or tracking. Data is shared with no one other than Google Cloud, for the processing described above. The use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Your choices

  • Exclude domains, or switch to manual mode or the local heuristic, in the options.
  • "Se déconnecter" (sign out) in the options revokes the extension's access to your Google account; you can also do it at myaccount.google.com/connections.
  • Daily counters delete themselves; for any question or request, contact {{CONTACT_EN}}.
